## 이번 변경과 검증

| 영역 | 구현한 동작 |
|---|---|
| 공개 경계 | 최상위·카드·관찰 필드 허용목록, 중첩 가격 거부, 연락 정보·미래·불가능한 날짜 거부. UI는 전역 공개 관찰만 읽는다. |
| 공개 검수 원장 v2 | 공개 행 전체와 연결된 카드 정보의 SHA-256을 연결한다. 출처·가격·상태·배송비·카드 정보 변경 시 재검수한다. ID만 저장한 기존 원장은 재검수가 필요하다. |
| 가져오기 | 신규 검수 기록을 메모리에서 동일 기준으로 검증한다. 무변경 dry-run, 단일 잠금, 복구 저널, 원본/dist/두 Worker/새 원장 처리와 중단 복구를 제공한다. |
| 체결 근거 | 수동 매물 페이지나 판매완료 배지만으로 verified sale을 만들지 않는다. 실제 정산 근거 참조는 비공개 원장에만 둔다. |
| Worker | PNG를 바이너리로 보존한다. 원본 바이트 기반 ETag와 10개 GET/HEAD/304 경로를 검증한다. |
| UI | 현재 입찰·낙찰 결과·정산 확인·공식 소매가를 구분한다. 탭/출처가 그래프와 연동하며 UTC offset 정렬, 전체 기록 수, 한국시간 표시를 수정했다. 모바일 필터 배치와 상세 높이를 개선했다. |
| 출처 확인 상태 | `coverage.state`를 미확인·접근 차단·부분 확인·범위 확인 완료로 구분한다. 확인 날짜와 명시한 범위를 검증하고, 7일이 지나면 갱신 지연을 표시한다. 범위 완료 후 0건이어도 플랫폼 전체에 매물이 없다고 표현하지 않는다. |
| 출시 관문 | 최근 7일의 서로 다른 예약 성공 2회/플랫폼을 직접 센다. 중복 ID/시각, 미래 기록, 과거 성공만 있는 현재 실패 수집기로 통과할 수 없다. |
| 운영 | refresh는 실패/차단 종료 코드를 구분한다. 철회 ID는 새 스냅샷에서도 억제하며 새 검수로 복원한 뒤 더 새로운 관찰만 수용한다. `health`는 DB를 바꾸지 않는다. 운영 DB·템플릿 경로는 실제 비공개 디렉터리만 허용하며 symlink/junction과 DB 파일 symlink를 거부한다. |
| 식별 | identity v2와 비공개 검토 대기함을 유지한다. 동일 인쇄 종류와 동일 실물 비교 조건을 구분하며 검토 승인이 공개 허가로 전환되지 않는다. |

회귀 시험은 **74개**다. 현재 Windows 작업공간에서는 73개 통과했고 파일 symlink 생성 권한 제한으로 1개를 건너뛰었다. 출처 상태의 날짜·범위, 가져오기 복구, DB/private directory junction 차단, 정적 빌드·검수 원장·PNG/Worker 검증을 확인했다. 공개 preflight는 73개 파일과 합성 데이터 경계를 통과했다. 브라우저에서는 합성 가격 0건과 390px·320px 모바일 출처 카드의 줄바꿈을 확인했다. 합성 비교 시나리오는 공개 데이터에 저장하지 않았다. GitHub의 새 필수 CI 결과는 이번 변경 push 후 확인한다.

자세한 명령·원장·복구 계약은 [PUBLICATION.md](PUBLICATION.md)에 있다. CI의 최종 결과는 PR의 필수 상태 검사를 확인한다.

## 2026-10-21 공개 초안 연결 추가

`PUBLICATION-EXPORT.md`에 설명한 로컬 내보내기 다리를 추가했다. 공개 허가·이력 저장 승인·미만료 원천 검토, 독립 시장 출처, 승인 해시가 유효한 동일 실물 식별 검토, 별도 최종 공개 승인까지 모두 맞아야 한다. 철회/복원 시각, 판매 정산 증거, 파일 경로와 해시도 다시 확인한다. 생성 파일은 `.ops-private/publication-export/drafts/`에만 저장하며, 정적 사이트 파일이나 배포를 수정하지 않는다. 테스트는 격리된 임시 자료만 사용했고 실제 운영 DB에는 관측값이 없다.

공개 비교키는 이제 비공개 무작위 비교 그룹 UUID와 검토된 복사본 식별값을 함께 해시한다. 시리얼만으로 재계산 가능한 공개 해시를 없앴고, UUID는 비공개 검토 대기함과 감사 원장에만 둔다. 여러 출처의 같은 실물임을 확인한 경우에만 검토자가 그룹 UUID를 재사용한다.

## 남은 구현과 외부 완료 조건

1. 승인된 운영 스냅샷과 identity v2 검토 결과를 공개 내보내기 단계에 연결한다. 비공개 스크린샷 메모와 소유자 보유 자료는 계속 제외한다.
2. 실제 공급처 접근·보관/표시 승인, API 키/피드와 허용 주기를 확인한 뒤 실제 수집기를 연결한다. 임의 endpoint나 인증 없는 수집을 추가하지 않는다.
   2026-10-21 공식 자료 확인: [번개장터 글로벌 파트너 포털](https://sell-global.bunjang.co.kr/)은 파트너용 상품·주문 API를 안내하고, [Open API 개요](https://api.bgzt.guide/)는 API 키 발급에 계약 서명과 파트너 계정 설정을 요구한다. 이 문서는 일반 중고 매물의 공개 모니터링 권한까지 확인해 주지 않으므로, 해당 범위의 서면 허가와 이용 조건을 확인하기 전에는 수집기를 활성화하지 않는다.
3. 공식 체크리스트의 텍스트 공개 권한과 정확한 전사를 검토한다. 목록 이미지나 카드 사진을 개발 예시로 재배포하지 않는다.
4. 실제 6개 플랫폼 전체/증분 수집과 예약 실행 2회/플랫폼, 두 플랫폼 동일 카드 비교를 검증한다. 코드 시험으로 대신 충족하지 않는다.
5. 실제 정정 수신 채널·담당자·운영 알림/백업 복구·사용자 과업 및 배포 호스트 검증을 완료한다. 사용자 지시 없이 문의나 초대 메시지를 발송하지 않는다.

공개 fixture는 합성 선수 1명, 실제 가격 0건이다. 테스트 호환용 ID를 실제 재고로 해석하지 않는다. `check:release` 종료 코드 2는 운영 증거 부족을 뜻하며 일반 코드 CI와 별도다. 기존 Sites 프로젝트에 대한 접근·배포는 이 공개 저장소와 독립되어 있다.
