# 현재 구현 범위

- 실제 플랫폼 collector와 승인된 공개 가격 데이터는 연결되지 않았습니다. 합성 테스트 통과는 6개 플랫폼 연동 증거가 아닙니다.
- 카드 식별 v2와 검토 대기함은 개발 중이며 실자료 검토·회귀 검증이 더 필요합니다.
- 공개 snapshot importer의 검수 원장 생성 순서와 원장-레코드 연결 검증에 개선이 필요합니다. 실자료를 import하거나 공개 운영에 투입하기 전에 고쳐야 합니다.
- 가격 비교 UI는 경매·체결 유형과 날짜 정렬, 출처별 비교 표시의 추가 검증이 필요합니다.
- 기존 Worker 빌드의 PNG 처리와 해당 경로의 검증을 보강해야 합니다. 로컬 정적 개발 서버는 이미지 원본 바이트를 제공합니다.
- 7일 내 예약 성공 집계, 철회 기록의 지속 처리, 실행 실패 종료코드는 운영 준비 과제입니다.
- 공식 목록·이미지·가격 데이터의 재사용 조건, 실호스트 측정·사용자 과업 검증·실제 Sites 배포는 별도 완료 기준입니다.

이 목록은 코드 협업의 시작점을 공유하기 위한 것입니다. 검증하지 않은 플랫폼 가격이나 사용자 재고를 예시 데이터로 넣지 마세요.
