# 현재 구현 범위

- 실제 자동 collector와 승인된 공개 가격 자료는 연결되지 않았다. 합성 테스트는 6개 플랫폼 연동 증거가 아니다.
- identity v2·비공개 검토 대기함을 공개 내보내기 경로에 연결하고 실자료로 검증해야 한다. 검토 승인은 자료 공개 허가가 아니다.
- 공개 가져오기·원장 행/카드 지문·정산 근거·중단 복구를 구현했다. 실제 증빙의 진위와 적용 범위는 담당자의 검수가 필요하다. 레거시 ID 원장은 재검수해야 한다.
- UI의 입찰/낙찰/체결/공식 소매가 필터·날짜 정렬·출처 연동과 모바일 상세를 보강했다. 실사용자 과업과 실제 호스트 성능 검증은 남아 있다.
- PNG 보존, Worker 10개 경로, 최근 예약 성공 집계, 실패 종료 코드, 지속되는 철회와 읽기 전용 health를 검증했다. 실제 OS 예약은 비활성이다.
- 운영 DB 철회는 이미 발행한 사이트를 자동 수정하지 않는다. 공개 자료 정정과 배포는 별도 작업이다.
- 공식 목록/사진/가격의 재사용 승인, 실제 공급처 전체 수집, 실호스트 검증·배포와 롤백은 별도 완료 조건이다.

실제 운영 DB·보유 카드·사진·검수 증빙을 이 저장소에 넣지 않는다. 공개 fixture의 실제 가격 기록은 0건을 유지한다. 실행·복구 명령은 [PUBLICATION.md](PUBLICATION.md)를 참고한다.
